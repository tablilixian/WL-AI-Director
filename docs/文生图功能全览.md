## 一、基础文生图（PromptBar）

| 功能 | 组件 | 文件位置 | 代码行 | 提示词来源 |
|------|------|---------|--------|-----------|
| **文生图** | PromptBar | `src/modules/canvas/components/PromptBar.tsx` | :40-97 | 用户直接在 UI 输入框键入，无预设 |
| **图生图（编辑）** | PromptBar | `src/modules/canvas/components/PromptBar.tsx` | :98-160 | 用户键入，自动加前缀 `"Edit this image: "` |

PromptBar 是画布底部的主要交互入口，支持 4 种模式：
- `generate` — 文生图（按钮标签："文生图"）
- `edit` — 图生图（按钮标签："图生图"）
- `video` — 文生视频（按钮标签："文生视频"）
- `video-edit` — 图生视频（按钮标签："图生视频"）

### 2.1 Prompt 增强（enhancePrompt）

模式对应的 5 种 system prompt (`:211-217`)：

| 模式 | 系统提示词 |
|------|-----------|
| `text-to-image` | "Optimize this image generation prompt. Add vivid visual details, composition, lighting, and artistic style." |
| `image-to-image` | "Optimize this image editing prompt. Focus on specific visual changes while maintaining the original composition." |
| `style-transfer` | "Enhance this style transfer prompt. Include specific artistic style details, color palettes, brush techniques..." |
| `background-replace` | "Improve this background replacement prompt. Describe the new environment in detail..." |
| `expand` | "Enhance this image expansion prompt. Describe what should naturally extend beyond the original boundaries." |

### 2.2 风格迁移（styleTransfer）— 10 种风格预设 (`:260-271`)

| 风格 key | 提示词 |
|----------|--------|
| `anime` | "Convert this image to anime style, maintaining the composition and key features. High quality anime illustration." |
| `oil-painting` | "Convert this image to oil painting style with rich textures and brush strokes." |
| `watercolor` | "Convert this image to watercolor painting style with soft edges and translucent washes." |
| `sketch` | "Convert this image to pencil sketch style with detailed line work and shading." |
| `pixel-art` | "Convert this image to pixel art style, 8-bit retro game aesthetic." |
| `cyberpunk` | "Convert this image to cyberpunk style with neon lights, futuristic elements..." |
| `ghibli` | "Convert this image to Studio Ghibli animation style, soft and dreamy." |
| `3d-render` | "Convert this image to 3D rendered style with realistic lighting and materials." |
| `comic` | "Convert this image to comic book style with bold lines and vibrant colors." |
| `pop-art` | "Convert this image to pop art style inspired by Andy Warhol and Roy Lichtenstein." |

### 2.3 图片扩展（expandImage）— 7 个方向 (`:311-319`)

| 方向 | 提示词 |
|------|--------|
| `all` | "Expand this image in all directions, naturally extending the scene." |
| `left` | "Expand this image to the left, naturally extending the scene." |
| `right` | "Expand this image to the right, naturally extending the scene." |
| `top` | "Expand this image to the top, naturally extending the scene." |
| `bottom` | "Expand this image to the bottom, naturally extending the scene." |
| `left-right` | "Expand this image to the left and right, naturally extending the scene." |
| `top-bottom` | "Expand this image to the top and bottom, naturally extending the scene." |

### 2.4 背景替换（replaceBackground）— 模板 (`:295`)

```
Replace the background of this image with: {backgroundDescription}. Keep the main subject intact and naturally blend it with the new background.
```

### 2.5 智能抠图（removeBackground）— 固定 prompt (`:336`)

```
Remove the background from this image, keeping only the main subject. Output a PNG with transparent background.
```

### 2.6 生成变体（generateVariants）— 动态模板 (`:362`)

```
Generate a variant of this image with {strength}% variation. Keep the main composition but change some details, lighting, or style. Create variation {i} of {count}.
```

## 六、API 适配层

位于 `services/adapters/imageAdapter.ts`（共 673 行）。

### 6.1 统一入口 `callImageApi()` (`:612-660`)

按 provider 路由到不同后端：

```
Drama Backend ────> callDramaBackendApi()
BigModel CogView ──> callCogViewApi()
Gemini Image ─────> callGeminiApi()
```

### 6.2 Drama Backend (`:180-287`)

| 项目 | 内容 |
|------|------|
| **文生图端点** | `POST /api/v1/generate/txt2image` |
| **图生图端点** | `POST /api/v1/generate/image2image` |
| **请求体** | `{ prompt, width, height }` |
| **返回** | JSON `{ full_url }`，处理后存 IndexedDB 返回 `local:{id}` |

### 6.3 BigModel CogView (`:89-175`)

| 项目 | 内容 |
|------|------|
| **端点** | `POST /api/paas/v4/images/generations` |
| **模型** | cogview-3-flash / cogview-4 / cogview-3-plus / cogview-3 |
| **尺寸映射** (`:100-105`) | `16:9 → 1280x720`, `9:16 → 720x1280`, `1:1 → 1024x1024` |
| **限制** | **不支持参考图**（:108），图生图时会降级为文生图 |

### 6.4 Gemini Image (`:373-607`)

| 项目 | 内容 |
|------|------|
| **模型** | `gemini-3-pro-image-preview` |
| **API** | `generateContent` with `responseModalities: ['TEXT', 'IMAGE']` |
| **参考图** | 支持 inlineData 方式传入（:394-418 注入角色一致性指令） |
| **图片提取** | 从 response candidates 提取 `inlineData`，转 Blob 存 IndexedDB（:570-595） |
