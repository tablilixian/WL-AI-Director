# 创意画布功能集成计划

## 定位声明

本项目拥有一套完整的工业级漫剧生成管线：
- 剧本拆解（StageScript）
- 角色/场景概念图生成（StageAssets）
- 导演工作台 - 首尾帧与视频片段生成（StageDirector）
- 视频合成与导出（StageExport）

**创意画布的定位**：帮助导演打磨角色、场景和分镜等中间产物，让 AI 辅助导演制作出更加符合导演想法的图片或视频短片。画布不做"生产"，只做"精修"。

---

## 实施路线图

### P0 - 核心打磨能力

#### 1. 多机位多角度生成
- **来源**：LibTV「多机位九宫格 / 多角度」
- **场景**：导演选中画布中的一张分镜图或场景图，想从不同机位/角度观察同一内容，选择最佳构图
- **集成方式**：
  - 在 ImageActionMenu 增加「多角度」入口
  - 弹出 MultiAnglePanel，选择机位/角度（可复用 StageDirector 的 cameraMovementGuides.ts）
  - AI 图生图生成不同角度的画面
  - 结果以多个图层或宫格排列图放入画布
- **现有基础**：StageDirector/NineGridPreview.tsx（机位/景别 UI）、cameraMovementGuides.ts（镜头术语）

#### 2. 角色三视图生成
- **来源**：LibTV「角色三视图」
- **场景**：导演导入角色定妆照到画布，在画布中直接生成正/侧/背三视图，对比后选择满意版本
- **集成方式**：
  - 在 ImageActionMenu 增加「三视图」入口
  - 复用或抽取 StageAssets/ThreeViewModal.tsx 的逻辑
  - 调用 AI 图生图生成三视图组合图
  - 结果以单张三视图组合图或三个独立图层放入画布
- **现有基础**：StageAssets/ThreeViewModal.tsx、TurnaroundModal.tsx

### P1 - 增强打磨能力

#### 3. 连贯分镜 / 剧情推演
- **来源**：LibTV「25宫格连贯分镜」「剧情推演四宫格」「画面时间推演」
- **场景**：
  - 剧情推演：导演画好一张关键帧，想看看前一格和后一格应该画什么
  - 连贯分镜：基于角色 + 剧情描述，一次生成 9/25 格连贯叙事序列
- **集成方式**：
  - 新增 StoryboardDeductionPanel（剧情推演四宫格）
  - 新增 CoherentStoryboardPanel（连贯分镜批量生成）
  - 结果以多图层或宫格组合图放入画布

#### 4. 电影级光影校正
- **来源**：LibTV「电影级光影校正 - 26 个主光点位 + 智能模式」
- **场景**：导演对角色图/场景图的光照不满意，希望精确控制打光方向和强度
- **集成方式**：
  - 新增 LightingControlPanel
  - 预设 8-12 个常见光位（正面光/侧光/逆光/顶光/伦勃朗光/蝴蝶光/轮廓光/底光等）
  - 选中图片 → 选择光位 → AI 图生图重新打光

### P2 - 锦上添花

#### 5. 画布内模型切换
- 在 PromptBar 增加模型选择下拉框
- 每个 PromptLayer 可独立选择生成模型
- 在 GenerationOptions 接口增加 modelId 字段

#### 6. Slash 快捷命令系统
- 选中图层后按 `/` 弹出功能快捷菜单
- 包含：多角度/三视图/风格迁移/光影校正/背景替换/扩图/抠图/变体等
- 减少顶部工具栏按钮数量，功能按需出现

#### 7. 视频分镜解析
- 导入外部视频或管线视频
- AI 自动拆解为关键帧序列
- 每个关键帧作为一个图层放入画布，供进一步精修


## 开发原则

1. **不破坏管线**：画布功能不侵入 StageScript/StageAssets/StageDirector/StageExport
2. **单向数据流**：管线 → 画布（导入精修）→ 管线（导出回流），不反向依赖
3. **复用优先**：优先抽取/复用已有组件（ThreeViewModal、NineGridPreview）
4. **增量开发**：每个功能独立开发、独立部署，互不阻塞
