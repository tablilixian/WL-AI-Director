# WL-AI-Director 提示词功能全览
> 整理范围：项目中所有与提示词（Prompt）相关的功能代码
> 分类方式：对话模型 / 生图 / 生视频

---

## 一、对话模型（Chat/LLM 对话生成）

这类提示词通过 Chat Completion API 调用 LLM，用于生成结构化的文本输出（剧本、视觉描述、分镜数据等）。

### 1.1 剧本解析

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/scriptService.ts` |
| **函数** | `parseScriptToData` |
| **用途** | 将原始剧本文本解析为结构化 JSON 数据 |
| **角色设定** | AI 剧本分析员 |
| **输出格式** | JSON `{title, genre, logline, characters[], scenes[], storyParagraphs[]}` |

### 1.2 分镜列表生成

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/scriptService.ts` |
| **函数** | `generateShotList` |
| **用途** | 为每个场景生成详细分镜头列表 |
| **角色设定** | 专业电影摄影师 |
| **参考信息** | 内置 30+ 种专业镜头运动类型 |
| **输出字段** | `actionSummary`, `cameraMovement`, `shotSize`, `visualPrompt`, `dialogue`, `characters`, `keyframes[]` |

### 1.3 剧本续写

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/scriptService.ts` |
| **函数** | `continueScript` / `continueScriptStream` |
| **用途** | 基于已有剧本内容续写后续情节 |
| **要求** | 保持原风格、人物性格、叙事节奏，续写长度为原剧本 30%-50% |

### 1.4 剧本改写

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/scriptService.ts` |
| **函数** | `rewriteScript` / `rewriteScriptStream` |
| **用途** | 对整个剧本进行系统性、创造性改写 |
| **要求** | 优化情节结构、增强戏剧冲突、深化人物情感、提升对话质量 |

### 1.5 美术指导文档生成

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/visualService.ts` |
| **函数** | `generateArtDirection` |
| **用途** | 生成全局 Art Direction Brief，确保后续所有视觉提示词的统一风格 |
| **角色设定** | 世界级美术指导 |
| **输出格式** | JSON `{colorPalette, characterDesignRules, lightingStyle, textureStyle, moodKeywords, consistencyAnchors}` |

### 1.6 角色视觉提示词生成

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/visualService.ts` |
| **函数** | `generateCharacterVisualPrompt` |
| **用途** | 基于角色信息 + 美术指导，生成详细的角色视觉描述 |
| **内容包含** | 面部特征、发型发色、体型比例、服装造型、标志性姿态、微动作特征、剪影线条美学、身体局部特写、动态动作 |

### 1.7 场景视觉提示词生成

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/visualService.ts` |
| **函数** | `generateSceneVisualPrompt` |
| **用途** | 纯场景/环境视觉描述 |
| **约束** | 严格禁止人物/角色出现，纯环境镜头 |

### 1.8 通用视觉提示词生成（含正负提示词）

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/visualService.ts` |

### 1.9 批量角色视觉提示词生成

### 1.10 角色九宫格造型设计

## 二、生图（Image Generation 图像生成提示词）

这类提示词最终发送给图像生成模型（Gemini Image 等 API），用于生成实际图片。

### 2.1 视觉风格常量

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/promptConstants.ts` |
| **常量** | `VISUAL_STYLE_PROMPTS` / `VISUAL_STYLE_PROMPTS_CN` |

6 种视觉风格的英文提示词和中文描述：

| 风格 Key | 风格名称 | 特点关键词 |
|----------|----------|------------|
| `live-action` | 真人实拍电影 | photorealistic, cinematic, 8K, 专业摄影 |
| `anime` | 日本动漫 | cel-shaded, 鲜艳色彩, Studio Ghibli/新海诚品质 |
| `2d-animation` | 经典 2D 动画 | 手绘风格, Disney/Pixar 品质, painterly 背景 |
| `3d-animation` | 3D CGI 动画 | Pixar/DreamWorks 风格, PBR 纹理, 次表面散射 |
| `cyberpunk` | 赛博朋克 | 霓虹灯光, Blade Runner 风格, 体积 fog |
| `oil-painting` | 油画风格 | impasto 笔触, 古典构图, Rembrandt 布光 |

### 2.2 负面提示词常量

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/promptConstants.ts` |
| **常量** | `NEGATIVE_PROMPTS`（角色通用）/ `SCENE_NEGATIVE_PROMPTS`（场景专用） |
| **用途** | 每个风格对应一组负面提示词，排除不想要的视觉元素 |
| **场景专用** | 在角色基础上额外排除人物/人形元素 |

### 2.3 角色九宫格图片生成

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/visualService.ts` |
| **函数** | `generateCharacterTurnaroundImage` |

| **要求** | 9 个面板等大、严格一致的角色设计、方形图片 |

### 2.4 图像生成（含参考图一致性）

| 项目 | 内容 |
|------|------|
| **文件** | `services/ai/visualService.ts` |
| **函数** | `generateImage` |
| **两种模式** | |
| **变体模式** | 更换服装但保持面部/发型/身份完全一致 |

## 三、生视频（Video Generation 视频生成提示词）

这类提示词发送给视频生成模型（Sora-2、Veo、BigModel 等 API）。

### 3.1 视频提示词模板

|------|------|

| **常量** | `VIDEO_PROMPT_TEMPLATES` |

| 模板 Key | 语言 | 适用模型 | 用途 | 核心约束 |
|----------|------|----------|------|----------|
| `sora2.chinese` | 中文 | Sora-2 | 普通视频生成 | 从参考图精确构图开始、流畅运动、角色/环境全程一致、中文配音 |

## 四、数据流全链路

```
用户输入剧本
    ↓  [对话模型] parseScriptToData
结构化数据（角色 / 场景 / 段落）
    ↓  [对话模型] generateArtDirection
美术指导文档（色彩 / 灯光 / 纹理锚点）
    ↓  [对话模型] generateCharacterVisualPrompt / generateSceneVisualPrompt
角色视觉描述 + 场景视觉描述
    ↓  [对话模型] generateShotList
分镜列表（含 cameraMovement, actionSummary）
    ↓  [对话模型] optimizeBothKeyframes / generateActionSuggestion
起始帧/结束帧视觉描述 + 动作描述
    ↓  [生图] buildKeyframePrompt + generateImage
关键帧图片
    ↓  [生视频] buildVideoPrompt + generateVideo
最终视频
```

全程可通过 **StagePrompts** UI 组件对每个节点的提示词进行查看、搜索和手动编辑。
