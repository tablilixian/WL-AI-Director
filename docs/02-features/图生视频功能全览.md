## 一、功能概述

图生视频（image-to-video）允许用户选择一张或多张画布图片，通过 AI 模型生成一段连贯视频。核心能力：

- **多图输入**：支持 1~N 张图片作为视频素材，按序排列
- **逐图 Prompt**：每张图片可设置独立提示词 + 全局 prompt
- **视频尺寸**：7 个预设（16:9/9:16/1:1/2:1）+ 自定义 W/H
- **视频时长**：3~15 秒，步长 100ms
- **镜头运动**：12 种预设（推/拉/摇/移/跟/旋转/抖动/升降）+ 强度 & 速度
- **灯光方案**：10 种预设（前/侧/逆/顶/底/伦勃朗/蝴蝶/霓虹/金色）+ 强度
- **对白/旁白**：毫秒级时间轴编辑器，支持多条记录排序和可视化时间条

## 二、组件架构与入口

```
ImageActionMenu (右键单图) ──┐
                              ├──> GenerateVideoPanel
InfiniteCanvas (多选底栏) ────┤        ↑
                              └──> InfiniteCanvas (重新生成浮动栏)
```

### 2.1 单图入口 `ImageActionMenu.tsx`

- `ImageAction` 类型新增 `'generate-video'`（line 39）
- 菜单分组 `'基于此图生成'` → `'AI 生成视频'`（line 99）
- 触发时设置 `showGenerateVideo = true`，渲染 `GenerateVideoPanel selectedLayerIds={[layer.id]}`
- 与 `'image-to-video'`（单图生视频，旧版操作）共存

### 2.2 多图入口 `InfiniteCanvas.tsx`

- 选中 **2+ image 层**（`selectedImages.length >= 2`）时显示底部浮动操作栏
- 按钮 "AI 生成视频" → `setGenerateVideoLayerIds(selectedImages)`
- 与单图右键菜单互斥（`hasSingleImageMenu` 检查）

### 2.3 重新生成入口 `InfiniteCanvas.tsx`

- 选中 `type: 'video'` + `operationType: 'image-to-video'` 的视频层时显示浮动栏
- 解析 `generationPrompt` JSON → 传给 `GenerateVideoPanel initialConfig`
- 详见 [第六节](#六重新生成流程)

### 3.4 `handleGenerate` 流程

```
1. 检查 canGenerate → 锁定 UI
2. 确定尺寸 (custom VS preset)
3. 获取活跃视频模型
4. 拼接 prompt:
   globalPrompt + 逐图描述 + 镜头prompt + 灯光prompt + 对白时间线
5. canvasModelService.generateVideo({ prompt, startImage, aspectRatio, duration })
6. 解析返回 URL (处理 video: / local: / data: 协议)
7. 构造 GenerationConfig 快照 → JSON.stringify → generationPrompt
8. addLayer({ type:'video', src, sourceLayerId, sourceLayerIds, generationPrompt, ... })
9. 1s 后自动关闭面板
```

### 3.5 `initialConfig` 还原逻辑

```tsx
const configApplied = useRef(false);
useEffect(() => {
  if (!initialConfig || configApplied.current) return;
  configApplied.current = true;
  // 还原所有 state: imageSequence, globalPrompt, sizePreset,
  // customSize, duration, camera, lighting, dialogues
}, [initialConfig]);
```

通过 `useRef` 保证只应用一次，防止 props 引用变化导致重复赋值。

## 四、数据流与状态管理

### 4.1 生成数据 → 视频层

| 字段 | 值 | 用途 |
|------|-----|------|
| `type` | `'video'` | 层类型 |
| `operationType` | `'image-to-video'` | 标识操作 |
| `sourceLayerId` | `imageSequence[0].layerId` | 首张来源 |
| `sourceLayerIds` | 所有图片 ID | 多来源（连接线用） |
| `generationPrompt` | `JSON.stringify(GenerationConfig)` | 存全部配置 |
| `duration` | `durationMs / 1000`（秒） | 总时长 |
| `src` | resolved URL | 视频播放源 |

### 4.2 重新生成数据流

```
视频层选中
  ↓
InfiniteCanvas 浮动栏
  ↓
解析 generationPrompt JSON → GenerationConfig
  ↓
点击"重新生成" → setRegenerateVideoConfig({ sourceLayerIds, config })
  ↓
渲染 GenerateVideoPanel initialConfig={config}
  ↓
用户修改 → 点击生成 → 新的视频层
```

## 五、连接线渲染

文件：`ConnectionLines.tsx`

### 5.1 过滤

```tsx
const layersWithSource = layers.filter(
  l => l.sourceLayerId || (l.sourceLayerIds && l.sourceLayerIds.length > 0)
);
```

同时兼容单源（`sourceLayerId`）和多源（`sourceLayerIds`）。

### 5.2 源解析

```tsx
const isMultiSource = layer.sourceLayerIds && layer.sourceLayerIds.length > 1;
const sourceIds = isMultiSource
  ? layer.sourceLayerIds!
  : (layer.sourceLayerId ? [layer.sourceLayerId] : []);
```

### 5.3 绘制

- 每条来源 → 目标，绘制立方贝塞尔曲线
- 颜色（`operationColors`）：`image-to-video` → `#8b5cf6`（紫色）
- 多源时每条连线标注角色标签
- 单源时在连线中点标注操作名

## 六、重新生成流程

### 6.1 触发条件

1. 画布选中一个 `type: 'video'` 且 `operationType === 'image-to-video'` 的层
2. 不同时选中 image 层（避免与图片操作栏冲突）
3. `generationPrompt` 字段存在且可解析为 JSON
4. 按钮"重新生成"可用

### 6.2 缺陷：`useEffect` 不触发

当前 `InfiniteCanvas` 的浮动栏使用 `useEffect` 监听 `selectedLayerId` 变化来设置 `regenerateVideoConfig` 为 `null`（用于关闭面板）。但 `GenerateVideoPanel` 是模态全屏覆盖，用户关闭后 `selectedLayerId` 未变，`useEffect` 不会重新触发，导致：
- 关闭面板后浮动栏状态可能未重置
- 需在 `onClose` 回调中显式 `setRegenerateVideoConfig(null)`

当前实现已通过 `onClose={() => setRegenerateVideoConfig(null)}` 解决。

### 6.3 数据源查找降级

```tsx
const sourceIds = videoLayer.sourceLayerIds ||
  (videoLayer.sourceLayerId ? [videoLayer.sourceLayerId] : []);
```

优先使用 `sourceLayerIds`，若不存在则降级到 `sourceLayerId`。

## 七、关键类型定义

```tsx
// 图片序列项
interface ImageSequenceItem {
  layerId: string;
  order: number;
  imagePrompt: string;
}

// 对白条目

  id: string;
  timestamp: number;       // 毫秒

  imageSequence: { layerId: string; imagePrompt: string }[];
  globalPrompt: string;
  sizePresetIndex: number;
  useCustomSize: boolean;
  customWidth: number;
  customHeight: number;
  durationMs: number;
  cameraId: string;
  cameraIntensity: number;
  cameraSpeed: number;
  lightingId: string;
  lightingIntensity: number;
  dialogues: DialogueEntry[];
}

// 右侧选项卡
type RightTab = 'prompt' | 'settings' | 'camera' | 'lighting' | 'dialogue';
```

## 八、已知问题与边界情况

### 8.1 `video:` 协议处理

`canvasModelService.generateVideo()` 返回的 URL 格式为 `video:vid_xxx`，需通过 `videoStorageService.getVideo()` 获取 blob，再用 `URL.createObjectURL()` 转为可播放 URL。已在 `handleGenerate` 中处理。

### 8.2 多源连接线 `sourceLayerIds` 缺失

- `ConnectionLines` 的 filter 原本只检查 `sourceLayerId`（单数），导致多来源视频层不绘制连接线
- 已修复：同时检查 `sourceLayerIds.length > 0`

### 8.3 单图 VS 多图默认序列

- 单图（通过 ImageActionMenu）：默认 `imageSequence = [{ layerId, order: 1, imagePrompt: '' }]`
- 多图（通过 InfiniteCanvas 浮动栏）：默认 `imageSequence = selectedLayerIds.map((id, i) => ({ layerId: id, order: i+1, imagePrompt: '' }))`

### 8.4 重新生成时来源图片可能已删除

- 视频层存储的是 `sourceLayerIds`（ID 数组）
- 如果来源图片已被删除，浮动栏中缩略图显示为空白占位
- `GenerateVideoPanel` 打开后，序列中缺失的图层不会显示预览（`imageLookup` 中查找不到）

### 8.5 生成中 UI 锁定

- `isGenerating` 为 true 时禁用所有表单交互和取消按钮
- 进度提示通过 `progress`(0-100) + `progressLabel`(文本) 显示
- 生成完成后延迟 1s 自动关闭面板

### 8.6 尺寸预设与自定义切换

- `useCustomSize` 控制使用 preset 还是自定义
- 切换 preset 或修改自定义值后，最终宽高在 `handleGenerate` 中确定
- aspectRatio 会在生成时映射到 `'16:9' | '9:16' | '1:1'`

## 九、后续优化方向

### 9.1 代码层面

| 优化项 | 说明 | 优先级 |
|--------|------|--------|
| 状态提取到 hook | `GenerateVideoPanel` 全部状态可提取为 `useVideoGenerationConfig`，减少组件行数 | 中 |
| 尺寸预设异步拉取 | 硬编码在常量中，未来可从服务端配置 | 低 |
| camera/lighting prompt 国际化 | promptEn 目前硬编码，可对接 i18n | 低 |
| 虚拟化时间轴 | dialogue 时间轴用 div 模拟，可替换为轻量级 timeline 组件 | 低 |

### 9.2 功能层面

| 优化项 | 说明 | 优先级 |
|--------|------|--------|
| 多模型切换 | 当前通过 `getActiveVideoModel()` 取全局模型，可改为面板内选择 | 高 |
| 进度回调优化 | 当前轮询或单次回调，可改为 SSE/WebSocket 实时 push | 中 |
| 视频预览 | 视频生成后提供播放器预览（替代 lightbox 模式） | 高 |
| 批量生成对比 | 同配置多次生成，并排对比结果 | 低 |
| 历史记录 | 保存每次生成配置和结果，方便回溯 | 中 |
| 模板保存 | 将 camera/lighting/dialogue 组合保存为模板 | 低 |

### 9.3 交互层面

| 优化项 | 说明 | 优先级 |
|--------|------|--------|
| 拖拽排序 | 右侧图片序列列表支持拖拽（当前有 `GripVertical` 图标但未实现） | 中 |
| 图片预览区域优化 | 预览区可设置为 2×2/3×3 网格 | 低 |
| 生成结果对比 | 重新生成后新旧视频并列对比 | 中 |

### 9.4 可靠性

| 优化项 | 说明 | 优先级 |
|--------|------|--------|
| 生成超时处理 | 生成超过 N 分钟自动提醒/取消 | 中 |
| 数据校验 | `generationPrompt` JSON 解析失败时显示错误信息而非静默失败 | 高 |
| URL 泄露 | `URL.createObjectURL()` 应妥善管理生命周期，避免内存泄漏 | 高 |
