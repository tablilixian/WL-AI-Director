## 二、Scene 1 正确分镜方案

在修改 shot-1 之前，先看 Scene 1（赵家峪惨案）应该拆成几个镜头，这样 shot-1 才能放对位置：

| 本场景镜头 | 内容 | 涉及角色 | 景别 | 时长 |
|-----------|------|---------|------|------|
| **Shot-1 (修改目标)** | 宁静的赵家峪黄昏 → 日军突袭打破平静 | 日军特工队、村民 | 全景→中景 | ~8s |
| Shot-1b (新建) | 秀芹家中被抓，挣扎 | 秀芹、日军 | 中景→近景 | ~6s |
| Shot-1c (新建) | 李云龙回村，目睹惨状 | 李云龙、警卫排 | 中景→特写 | ~6s |

**当前 shot-1 实际对应的是场景 5（兵临城下）的镜头**，被错误分配到了场景 1。

## 三、逐项修改步骤（UI 操作）

在工具的导演工作台（StageDirector）中找到 shot-1，按以下顺序逐项修改：

---

### 步骤 1: 修改 actionSummary

**修改原因**: 当前描述"集结部队攻打平安县城"不符合场景 1 的剧情。

**当前值**:
```
李云龙率领部队在赵家峪村口集结，准备攻打平安县城。
```

**修改为**:
```
赵家峪村口的宁静黄昏被打破，山本特工队从三面突袭村庄，残阳如血，杀机四伏。
```

**修改要点**:
- 时间锚点：明确"黄昏"
- 事件锚点："宁静被打破"（不是集结）
- 反派出场：点明"山本特工队"
- 视觉锚点："残阳如血"

---

### 步骤 2: 修改 dialogue

**修改原因**: 当前为空。但剧本中第一个镜头以**音效驱动**（枪声、鸟飞），无对白，dialogue 应留空但加音效注释。

**当前值**: (空字符串)

**修改为**:
```
(音效) 乌鸦叫声、风声 → 消音步枪闷响 → 枪声大作、惨叫声、犬吠
```

**修改要点**:
- 第一个镜头没有台词，靠音效营造氛围
- 用 `(音效)` 标注，与对白区分
- 按时间顺序列出音效变化

---

### 步骤 3: 修改 cameraMovement

**修改原因**: 当前填的是 "Wide Shot"——这是景别不是运镜。

**当前值**: `Wide Shot`

**修改为**: `Crane Down Shot`

**修改要点**:
- 开场用 Crane Down（升降下降），从高空俯瞰村庄缓缓降下，有"上帝视角"感
- 日军突袭时切换到 `Handheld Shake`（手持晃动），制造紧张感
- 两个运镜用 `/` 分隔：`Crane Down → Handheld Shake`

---

### 步骤 4: 修改 shotSize

**修改原因**: 当前 "Wide Shot" 作为景别是对的，但描述可以更精确。

**当前值**: `Wide Shot`

**修改为**: `Extreme Wide Shot → Full Shot`

**修改要点**:
- 开场用 Extreme Wide Shot（极远景）展现村庄全貌
- 突袭后切换到 Full Shot（全景）展现日军冲入
- 用箭头表示变化

---

### 步骤 5: 修改 characters

**修改原因**: 当前所有6个角色都在，严重错误。

**当前值**: `["1", "2", "3", "4", "5", "6"]`

**角色对照表**:
| ID | 角色 | 是否应在场 | 原因 |
|----|------|-----------|------|
| 1 | 李云龙 | ❌ | 此时他不在赵家峪，惨案后才赶到 |
| 2 | 杨秀芹 | ❌ | 她在屋内，但此时尚未出场 |
| 3 | 赵刚 | ❌ | 不在赵家峪 |
| 4 | 山本一木 | ✅ | 他率队突袭 |
| 5 | 楚云飞 | ❌ | 不在赵家峪 |
| 6 | 张大彪 | ❌ | 不在赵家峪 |

**修改为**: `["4"]`（只保留山本一木的角色ID）

**修改要点**:
- 第一个镜头没有主要角色出场，以群演（日军特工队、村民）为主
- 山本一木作为特工队长，可以在镜头中一闪而过
- 群演由系统自动补充，不需要在 characters 中标注

---

### 步骤 6: 修改 start keyframe visualPrompt

**修改原因**: 当前 start 帧描述错误（集结部队），且用了40次重复套话。

**当前值**:
```
全景展现赵家峪村口，夕阳西下，炊烟袅袅，李云龙等战士在村口集结，
军装鲜明，背景为冷色调的战争场景，光影对比强烈，营造出战争的压抑氛围。
```

**修改为**:
```
赵家峪村口的黄昏全景。冬日残阳如血，将土坯房染成暗金色。枯树如鬼爪般伸向天空。 
炊烟从屋檐升起，宁静中透着诡异。远处树林突然惊起一群飞鸟——打破寂静的第一个信号。
镜头从高空缓缓下降(Crane Down)，掠过茅草屋顶，能看到村口放哨的民兵正在打盹。
画面边缘，阴影中隐约有黑色制服的身影在移动。
暖金色夕阳与深蓝阴影形成强烈冷暖对比。电影级宽幅构图，胶片颗粒质感。
```

**修改要点**:
- **具体画面**: 土坯房、枯树、飞鸟、哨兵——让人能"看见"
- **色调**: "暖金色夕阳 vs 深蓝阴影"——具体的颜色对比，不是"冷色调微妙红色调"
- **动态元素**: "飞鸟惊起"——暗示危险将至
- **运镜提示**: "镜头从高空缓缓下降"——与 cameraMovement 一致
- **构图参考**: "电影级宽幅构图，胶片颗粒质感"

---

### 步骤 7: 修改 end keyframe visualPrompt

**修改原因**: 当前 end 帧只是"镜头推进"，没有画面内容的变化。

**当前值**:
```
镜头缓慢推进，聚焦于李云龙的坚毅面容，他的眼神中透露出英勇和决心。
```

**修改为**:
```
镜头骤然推进(Snap Zoom)，聚焦到村口近景。残阳的暗金色余光中，三名日军士兵清晰可见——土黄色昭和军装，三八式步枪上的刺刀泛着寒光，钢盔下的面孔轮廓分明。他们从三个方向突入画面，皮靴踏碎泥路上的枯枝和土块。背景是斑驳的土坯墙，墙皮剥落露出夯土肌理，墙根堆着干草和农具。放哨的民兵在门楼阴影中无声倒下，消音步枪的枪口烟在昏暗中弥漫。村民转身欲逃的脸上写满惊恐，能看清他们粗布衣裳的补丁和脸上的尘土。夕阳的暖金与墙角的深蓝阴影形成强烈对比，虽是黄昏暗光，但每个细节都清晰可辨——土墙的裂缝、泥路的车辙、日军军装上的领章。2秒内宁静被彻底撕碎，构图从稳定的全景骤变为晃动的近景，仿若战地记者的手持摄影。
```

**修改要点**:
- **节奏变化**: "宁静→2秒内被撕碎"——明确节奏转变
- **具体动作**: "消音步枪闪光→哨兵倒下→三面突入"——可看见的动线
- **感官提示**: "靴子踏碎枯枝"——听觉+视觉
- **运镜风格**: "稳定的全景→晃动的中景"——与 start 帧形成对比
- **摄影术语**: "逆光剪影效果"——具体的视觉风格

---

### 步骤 8 (可选): 添加第三关键帧

**修改原因**: 这个镜头从"宁静"到"突袭"变化剧烈，首尾两帧跨度太大，中间过程不可控。

**新增强度**: 建议添加一个 **mid 关键帧**（如果 UI 支持）。

飞鸟惊起的特写。乌鸦从枯树中扑棱棱飞起，羽毛在逆光中呈现半透明。

## 六、UI 操作指引（分步图文步骤）

假设你的 UI 界面如下结构：

```
导演工作台
├── 场景列表 (左侧)
│   └── 场景 1: 赵家峪惨案 (当前选中)
├── 镜头列表 (中间)
│   ├── Shot-1 ← 你在这里操作
│   ├── Shot-2
│   └── ...
└── 镜头编辑面板 (右侧/下方)
    ├── actionSummary (文本框)
    ├── dialogue (文本框)
    ├── cameraMovement (下拉/文本)
    ├── shotSize (下拉/文本)
    ├── characters (多选/标签)
    └── keyframes (可折叠)
        ├── Start Frame
        │   └── visualPrompt (大文本框)
        └── End Frame
            └── visualPrompt (大文本框)
```

### 操作顺序（按依赖关系排列）

```
第1步: characters
  → 删除 1,2,3,5,6，只保留 4（山本一木）
  → 原因: 其他角色此时不在赵家峪

第2步: actionSummary
  → 全选删除，粘贴新的描述
  → 原因: 剧情方向完全错误

第3步: dialogue
  → 粘贴音效描述
  → 原因: 第一个镜头以音效驱动

第4步: cameraMovement & shotSize
  → 将"Wide Shot"改为"Crane Down → Handheld Shake"
  → 将另一个"Wide Shot"改为"Extreme Wide Shot → Full Shot"
  → 原因: 当前填反了/不精确

第5步: start keyframe
  → 全选删除旧文本，粘贴新的视觉描述
  → 原因: 旧描述与剧情不符且过于通用

第6步: end keyframe
  → 全选删除旧文本，粘贴新的视觉描述
  → 原因: 旧 end 帧与 start 几乎没有区别

第7步 (验证): 检查修改后效果
  → 对照第五节完整版本确认一致性
  → 点击"保存"按钮
```

## 七、常见问题 FAQ

### Q1: 修改后生成的图片还是不对怎么办？

A: 
1. 确认 **characters** 是否只选了山本一木（角色 ID 4）——如果还有李云龙，AI 会试图画出他
2. 确认 **sceneId** 是否正确指向赵家峪场景——如果指向了平安县城场景，画面会崩塌
3. 确认场景参考图（scene reference image）已经生成了赵家峪的图——没参考图的话 AI 自由发挥

### Q2: 我的 UI 上没有 cameraMovement 字段怎么办？

A: 将运镜描述合并到 keyframe 的 visualPrompt 中。例如在 start 帧第一句写"镜头从高空缓缓下降(Crane Down)"，end 帧写"手持晃动运镜(Handheld)"。AI 能理解这些指令。

### Q3: 角色 ID 不知道对应谁？

对照表（根据你的 JSON 导出）：
- ID "1" → 李云龙
- ID "2" → 杨秀芹
- ID "3" → 赵刚
- ID "4" → 山本一木
- ID "5" → 楚云飞
- ID "6" → 张大彪
- ID "char-1783924332056" → 被捕以后的杨秀琴

### Q4: 我的 UI 上只有 start 帧没有 end 帧？

A: 那就只修改 start 帧的 visualPrompt，把终态描述写在 start 帧里。效果相当于"只有一帧全自动"。
