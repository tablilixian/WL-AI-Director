# 视频生成功能扩展需求梳理

> 目的: 梳理现有 API 能力与当前 UI 的差距，明确扩展方向
> 来源: api.md + VideoGenerator.tsx + videoService.ts + imageAdapter.ts

---

## 一、现有视频 API 一览

| 端点 | 技术 | 核心参数 | 当前 UI 是否覆盖 |
|------|------|---------|----------------|
| `/image2videomsr` | MSR 多帧超分 | prompt, width, height, duration, fps, image1~4, background | ⚠️ adapter 存在，UI 未暴露 fps/多图/background |
| `/image2videomkr` | MKR 多关键帧插值 | prompt, width, height, duration, fps, images[{image, frame_index}] | ❌ 完全未接入 |
| `/image2videomkrgrid` | MKR 宫格视频 | prompt, width, height, duration, fps, image, gridtype, frame_indexs | ❌ 完全未接入 |
| `/deduction` | 剧情推演 VLM+LLM | image, analysis_prompt, deduction_prompt | ❌ 完全未接入 |
| BigModel 异步 | 智谱系列 (sora-2/cogvideox/vidu2) | prompt, image_url, duration, size | ✅ 已覆盖 |

VideoGenerator (当前)

### 当前生成流程简化版

```
用户点击"生成" → buildVideoPrompt() 拼提示词 → videoService 调 API → 返回 base64 → 预览
                                  ↑ 只用了 actionSummary + cameraMovement + cameraChoreography
                                  没有用 fps、分辨率、背景图、多帧控制等参数
```

## 三、能力差距分析

### 3.1 未利用的 API 参数

| 参数 | 所属 API | 当前 UI | 潜在价值 |
|------|---------|--------|---------|
| `fps` | msr/mkr/mkrgrid | 硬编码 30，不可调 | 高帧率(60fps)慢动作或低帧率节省算力 |
| `width/height` | msr/mkr/mkrgrid | 由比例推断，不可调 | 自定义分辨率（720p/1080p/4K） |
| `images[]` 多关键帧 | mkr | 只有首尾两帧 | 复杂动作可传3~5帧精确控制 |
| `image1~4` 多参考图 | msr | 只用了首帧 | 多角色/多角度参考 |
| `background` 背景图 | msr | 未使用 | 分离前景背景处理 |
| `gridtype` 宫格类型 | mkrgrid | 未使用 | 4/6/9宫格分镜视频 |
| `frame_indexs` 帧位置 | mkrgrid | 未使用 | 控制每个宫格的播放时机 |

### 3.2 完全未接入的能力

```
1. MKR 多关键帧视频 (image2videomkr)
   └── 可以传 3~5 张关键帧精确控制中间过程
   └── 适合: 复杂动作、表情变化、运镜复杂的镜头

2. MKR Grid 宫格视频 (image2videomkrgrid)  
   └── 一张图切成宫格分别生成视频
   └── 适合: 分镜对比、多视角同时展示

3. 剧情推演 (deduction)
   └── 分析当前帧画面 → 推演下一帧描述
   └── 适合: AI 辅助分镜创作
```

## 四、UI 扩展方案

### 4.1 方案一：在现有 VideoGenerator 中增加高级选项（推荐）

```
VideoGenerator (扩展后)
├── 模型选择下拉菜单
├── Veo Fast 清晰度切换
├── 画面比例选择
├── 视频时长选择
│
├── [新增] 展开"高级设置" (Collapsible)
│   ├── FPS 选择器 (24/30/60)
│   ├── 分辨率预设 (720p/1080p/4K)
│   ├── 运动强度滑块
│   └── 背景图选择（从场景资产中选）
│
├── [新增] 关键帧管理
│   ├── 首帧预览 + 编辑
│   ├── 尾帧预览 + 编辑
│   ├── [+] 添加中间帧 (mkr 模式可用)
│   └── 帧时间轴拖拽调整位置
│
├── [新增] 生成模式切换
│   ├── 单图模式 (i2v)
│   ├── 首尾帧模式 (keyframe interpolation)
│   └── 多关键帧模式 (mkr) ← 新
│       └── 宫格视频 (mkrgrid) ← 新
│
├── 提示词编辑按钮
├── 视频预览播放器
└── 生成/重新生成按钮
```

### 4.2 方案二：独立的高级视频面板

如果不想把 VideoGenerator 搞得太复杂，可以新增一个 `AdvancedVideoPanel` 组件，通过按钮切换：

```
导演工作台 最右侧区域 分两个 Tab:
├── [基本] → 现有 VideoGenerator
└── [高级] → AdvancedVideoPanel (新)
    ├── 生成模式: MSR / MKR / MKR Grid / 剧情推演
    ├── 多关键帧管理 (MKR)
    │   ├── 从当前镜头导入首尾帧
    │   ├── 拖拽添加中间帧 (从场景/角色资产中选)
    │   └── 帧在时间轴上的位置 (%)
    ├── 宫格设置 (MKR Grid)
    │   ├── 宫格数量: 4/6/9
    │   └── 各宫格帧位置设置
    ├── 分辨率 & FPS 控制
    ├── 背景图选择
    └── 生成按钮
```

## 五、建议实施优先级

| 优先级 | 功能 | 工作量 | 收益 |
|--------|------|--------|------|
| P0 | 高级设置折叠面板 (fps/分辨率/运动强度) | 小 | 参数可控，用户感知明显 |
| P1 | 多关键帧模式 MKR 接入 | 中 | 你的15秒视频方案可精确控制中间帧 |
| P2 | 宫格视频 MKR Grid | 中 | 分镜对比新能力 |
| P3 | 剧情推演 deduction | 大 | 可辅助创作，但偏离"生成"核心 |
| P4 | 背景图/多参考图上传 | 中 | 提升画质 |

## 六、我理解的需求（请你确认）

你说"把视频接口用起来"、"扩充当前视频生成 UI"，我理解你想做的是：

1. **当前 VideoGenerator 只用了 Drama Backend 的 MSR 接口**（还要通过 BigModel 兜底），但 MKR 多关键帧接口虽然 adapter 写好了，UI 上根本没有入口
2. **最右侧区域可以加一个"高级"面板**，把 fps、分辨率、多关键帧设置放进去
3. **你的 15 秒视频方案**（首帧→尾帧之间逐秒分解）如果用 MKR 接口传 3~5 张中间帧，中间过程会更可控

你看看这个方向对不对？有没有需要调整的地方？
