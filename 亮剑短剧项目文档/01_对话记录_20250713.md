# 亮剑短剧项目 - 对话记录 #1

**日期**: 2025-07-13
**参与人**: 用户 (项目负责人) + AI 助手

---

## 一、项目背景

### 1.1 当前项目概况

本项目基于 **WL AI Director (AI 漫剧工场)** 平台，这是一个 AI 一站式短剧/漫剧生成平台，采用 "Script-to-Asset-to-Keyframe" 的工业化工作流。

**技术栈**: React 19, TypeScript, Zustand, IndexedDB, PocketBase
**核心能力**: 一句话生成完整短剧，从剧本到成片全自动化，支持角色一致性、场景连续性与镜头运动控制。

### 1.2 用户需求

用户希望利用该平台，制作一部以**亮剑**（电视剧）为题材的**抗日短剧**，参考原剧中的经典场景进行复刻。

---

## 二、AI 对项目的分析

### 2.1 项目优势（与该需求的匹配度）

| 模块 | 匹配点 |
|------|--------|
| **StageScript (剧本)** | 可输入亮剑经典场景描述，AI 自动拆解为分镜脚本 |
| **StageAssets (资产)** | 可生成李云龙、赵刚、楚云飞等角色定妆照，以及战场、指挥所等场景 |
| **StageDirector (导演)** | 精准控制每个镜头的首帧/尾帧，确保角色一致 |
| **StageExport (导出)** | 可导出成片，支持时间轴预览 |

### 2.2 抗日题材的特殊需求

- **视觉风格**: 建议选择 `live-action`（写实风格）或自定义战争题材风格
- **画面比例**: 建议 `16:9` 横屏，适合战争大场面
- **色调方向**: 偏暗调、土黄色/灰绿色系，体现抗战年代感

## 三、亮剑经典场景推荐

以下是《亮剑》中最适合复刻的经典场景，按推荐优先级排列：

### ⭐ 第一梯队（强烈推荐）

#### 1. 平安县城之战 — "二营长，你他娘的意大利炮呢！"

- **原剧地位**: 全剧最经典场面，出圈梗
- **剧情概要**: 李云龙为救被山本抓走的秀芹和新婚妻子，率独立团攻打平安县城。秀芹在城楼上被绑，李云龙含泪下令开炮。
- **推荐理由**:
  - 情感冲突极强（家国 vs 个人）
  - 台词极度出圈（意大利炮梗）
  - 场面宏大（攻城战）
  - 悲剧英雄主义色彩浓厚
  - 短剧节奏紧凑，适合3-5分钟改编

#### 2. 李家坡之战 — 土工战术 + 手榴弹雨

- **原剧地位**: 展现李云龙战术天才的经典战役
- **剧情概要**: 山崎大队占据李家坡有利地形，正面进攻伤亡惨重。李云龙采用土工掘进战术，挖战壕接近日军阵地，然后全员投掷手榴弹。
- **推荐理由**:
  - 战术智慧突出（土工作业）
  - 视觉效果震撼（3600颗手榴弹齐飞）
  - 战斗节奏明确（前期吃紧 → 战术转折 → 大胜）
  - 适合展示 AI 的镜头调度能力

#### 3. 骑兵连冲锋 — "骑兵连，进攻！"

- **原剧地位**: 最悲壮的场景之一
- **剧情概要**: 孙德胜率骑兵连与日军骑兵联队激战。弹尽粮绝、战友全部牺牲、自己被砍断手臂后，仍单臂举刀高喊"骑兵连，进攻！"
- **推荐理由**:
  - 悲壮程度极高
  - 视觉冲击力强（骑兵冲锋）
  - 台词简短有力（易于传播）
  - 时长可控（2-3分钟即可完整呈现）

---

### ⭐ 第二梯队（推荐）

#### 4. 伏击日军观摩团

- **剧情概要**: 李云龙设伏歼灭日军华北方面军军官观摩团
- **亮点**: "老子打的就是精锐！" 经典台词；体现了独立团的伏击战术

#### 5. 赵家峪惨案 / 山本特工队袭击

- **剧情概要**: 山本特工队偷袭赵家峪，李云龙新婚妻子秀芹被抓，村民遭屠杀
- **亮点**: 紧张感强；可作为平安县城之战的前情铺垫

#### 6. 大闹聚仙楼

- **剧情概要**: 李云龙与楚云飞在日军宴会上联手刺杀日军军官
- **亮点**: 两位英雄首次合作；动作场面密集

---

### ⭐ 第三梯队（可选）

#### 7. 李云龙 VS 楚云飞 — 淮海战役对决

- **剧情概要**: 国共内战，昔日好友各为其主，战场相见
- **亮点**: 情感复杂，超越抗日题材的深度
- **注意**: 相比抗日题材，可能偏离主题

#### 8. 和尚魏大勇之死

- **剧情概要**: 魏和尚被黑云寨土匪杀害
- **亮点**: 让人痛惜的角色牺牲
- **注意**: 虐心情节，需考虑观看体验

#### 9. 雪夜宰马

- **剧情概要**: 极度艰苦条件下部队断粮，李云龙含泪下令宰杀战马充饥
- **亮点**: 展现抗战的艰苦卓绝

## 四、场景选择建议

### 推荐组合方案

鉴于短剧的篇幅限制，建议选取 **2-3个场景** 串联成一个完整故事：

#### 方案 A：情感冲突线（强烈推荐）

```
场景1: 赵家峪惨案（起因）→ 场景2: 平安县城之战（高潮）→ 场景3: 李云龙含泪开炮（结局）
```
- **篇幅**: 5-8分钟
- **特点**: 情感完整，起承转合明确，传播性强

#### 方案 B：纯战斗线

```
场景1: 李家坡之战（战术智慧）→ 场景2: 伏击观摩团（伏击作战）
```
- **篇幅**: 4-6分钟
- **特点**: 战斗场面密集，节奏紧凑

#### 方案 C：英雄群像线

```
场景1: 骑兵连冲锋（悲壮）→ 场景2: 平安县城之战（高潮）
```
- **篇幅**: 5-7分钟
- **特点**: 兼顾多角色，展现不同层面的抗战精神

## 八、第四次对话纪要

**时间**: 同一日（2025-07-13）继续

**用户需求**: 分析项目中角色提示词与我的提示词差距的原因，将优化点整理为独立文档。

**产出成果**: `04_项目优化点清单.md`

### 8.1 问题根因分析

1. **OP-001**: 系统 prompt 未要求历史准确性 → AI 生成"深棕色军装、手持大刀"
2. **OP-002**: 中文输出丢失英文电影摄影术语 → "光影对比强烈" vs "Rembrandt lighting, chiaroscuro"
3. **OP-003**: `generateCharacterVisualPrompt` 不输出 negative prompt → 无法排除"磨皮/微笑/光鲜"
4. **OP-004**: 场景提示词硬编码 `'anime'` → 不论选什么风格都走动漫
5. **OP-005**: 质量标签中英混杂 → 重复追加或风格不一致
6. **OP-006**: 衣橱系统未与剧本场景联动 → 需要手动创建变体
7. **OP-007**: Negative prompt 未传递到 API 调用层 → 生成了但没用上
8. **OP-008**: 角色 visualPrompt 被自动覆盖 → 手动编辑成果丢失

### 8.2 优先级排序

```
第一轮快赢（改 prompt 模板即可）
  OP-001 → OP-002 → OP-004 → OP-005

第二轮逻辑修改
  OP-003 → OP-007

第三轮功能增强
  OP-006 → OP-008
```

## 九、第五次对话纪要

**时间**: 同一日（2025-07-13）继续

**用户需求**: 分析项目 JSON 导出数据中分镜（shots）部分的优缺点，给出改进方案

**输入**: 项目完整 JSON 导出（含27个镜头、9个场景、7个角色）

**产出成果**: `04_项目优化点清单.md` 中新增 OP-009 ~ OP-017（分镜专项）

### 9.1 分镜部分总体评价

**优点**:
- 基本结构完整（shot ID、sceneId、运镜、景别、关键帧首尾帧）
- 关键帧 pending 状态说明流程正确
- shotSize / cameraMovement 字段有定义

**缺点（9项）**:

| 编号 | 核心问题 | 严重程度 |
|------|---------|---------|
| OP-009 | 镜头与剧本场景严重错位（赵家峪惨案的镜头混入了集结内容） | 🔴 |
| OP-010 | 27个镜头中23个 dialogue 为空，经典台词全部丢失 | 🔴 |
| OP-011 | 关键帧提示词40+次重复"冷色调带有微妙红色调光影对比强烈" | 🔴 |
| OP-012 | 角色分配与剧本不符（秀芹被抓后还在城外战斗队伍中） | 🔴 |
| OP-013 | 高潮段（开炮→牺牲）只有3个镜头，密度不足 | 🟡 |
| OP-014 | 关键帧未引用已生成的角色/场景参考图，影响一致性 | 🟡 |
| OP-015 | 运镜类型严重单一（Dolly 9次、Tracking 7次，缺乏 Crane/POV等） | 🟡 |
| OP-016 | 只有首尾帧，复杂动作缺少中间关键帧控制 | 🟢 |
| OP-017 | 剧本中的视觉细节（手指发白、击发绳、衣角碎片）全未覆盖 | 🟢 |

### 9.2 关键发现

1. **场景错位的根因**: storyParagraphs 有9段但剧本只有5个场景，AI 按段落数生成了9个 sceneId 导致映射混乱
2. **台词丢失的根因**: 分镜生成只用了 storyParagraphs 的概括文本，没有从 rawScript 中提取具体对白
3. **提示词雷同的根因**: artDirection.consistencyAnchors 被机械拼接到每个关键帧，AI 也不要求每个镜头唯一性
4. **角色错配的根因**: 没有"角色在场约束"，AI 把全部角色分配给所有镜头

### 9.3 实施优先级更新

```
第一轮快赢（改 prompt 模板）: OP-001→002→004→005→011→017
第二轮分镜逻辑修正:         OP-009→010→012→015
第三轮数据流打通:           OP-003→007→014
第四轮功能增强:             OP-006→008→013→016
```

## 十一、第七次对话纪要

**时间**: 同一日（2025-07-13）继续

**用户需求**: 针对 shot-1 生成一段15秒视频的完整提示词，要求精确到秒，包含场景/人物/光影/运镜描述

**产出成果**: `06_Shot1_15秒视频生成提示词.md`

### 11.1 文档结构

按"四幕"结构将15秒分为：

| 幕 | 时间段 | 情绪 | 镜头数 |
|----|--------|------|--------|
| 第一幕：宁静 | 0s-4s | 祥和→暗流 | 4秒 |
| 第二幕：爆发 | 4s-8s | 突变→冲击 | 4秒 |
| 第三幕：混乱 | 8s-12s | 混乱→惨烈 | 4秒 |
| 第四幕：定格拉远 | 12s-15s | 悲壮→凝固 | 3秒 |

### 11.2 每秒钟包含

每个秒级段落含：
- **画面**: 具体可见的元素（什么人/物/动作）
- **运镜**: 推拉摇移跟的具体方式
- **光线**: 光源方向/颜色/强度变化
- **色调**: 主色调+辅色调
- **声音**: 配合画面的音效提示

### 11.3 配套产出

- 可复制的完整 Positive Prompt
- 首帧提示词（可先生成首帧图）
- 尾帧提示词（已按用户反馈优化日军军装+村庄细节）
- 参数配置建议表
- 分段时间轴卡片（快速参考）
- 降级方案（如果15秒生成失败，拆为2个镜头）
